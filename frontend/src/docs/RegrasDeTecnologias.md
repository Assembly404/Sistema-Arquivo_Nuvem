 <!-- Este Arquivo serve como um manual de regras de como deve ser a implementacao de qualquer componente em react -->

### Regra 1:
Todo e qualquer componente deve ter uma imagem base na raiz do projeto dentro da pasta docs, se nao for o caso deve perguntar por uma proposta de modelo que ser discutido para implementacao do componente

### Regra 2:
A identidade Visual do Sistema esta documentada e essa regra nao pode ser violada mas ser seguida

### Regra 3:
O dominio da aplicacao deve ser mantido e respeito sempre se alinhando com o contexto e com permissao de referencias externas desde que essas sejam referencias justificadas e criticamente avaliadas para o dominio ou escopo da aplicacao

## Regra 4:
As principais tecnologias na implemtentacao de componentes e o react e o css puro como qualquer outro compontente implementado no sistema

### Regra 5:
Existe espaco para elaboracao de um componente que nao esteja nos requesitos e na documentacao do sistema mas se atrelam ao dominio da aplicacao

### Regra 6:
O Componente deve respeitar as regras de experiencia de usuario, responsividade
